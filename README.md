# Maram Raphael Samson — Portfolio

Personal portfolio for **Maram Raphael Samson**, software engineer and founder from Jos, Nigeria. The site presents selected products, engineering work, experience, and contact details.

🌐 **Live site:** [maramraphaelsamson.github.io/MaramRaphaelSamson](https://maramraphaelsamson.github.io/MaramRaphaelSamson/)

## Tech stack

- **HTML5** — semantic page structure and accessible content
- **CSS3** — responsive layouts, design tokens, project cards, and animations
- **Vanilla JavaScript** — mobile navigation, scroll progress, and reveal-on-scroll effects
- **SVG** — lightweight project preview artwork
- **GitHub Pages** — static hosting and deployment
- **Google Fonts** — DM Sans, Manrope, and DM Mono

This is a lightweight static site: no frontend framework, package manager, or build step is required.

## Run locally

Open `index.html` in a browser, or serve the repository root with any static file server. For example:

```bash
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).
